# The paper: records to counts, tables, figures, the build and its checks

Run from the workspace root in this order: `data.py`, `PPML_PARTS_NAME=parts-v<n> data_v68.py`, `experiment_v82.py`, then `PPML_PARTS=… PPML_STUDIES=… build.py <n> --check` (or without `--check` to render the Word file), then the checks (`verify_v68.py`, `check_claims_v68.py`, `style_check.py <n>`, `claims_audit.py`), the deck (`figures_pptx.py <n>`), the supporting document, the IEEE Access renderings and `release_package.py <n>`. `Docs/SCRIPTS-MAP.html` maps each script to the part of the paper it serves.

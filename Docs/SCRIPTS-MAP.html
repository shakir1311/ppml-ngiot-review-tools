Regenerated 2 November 2026 by scripts/paper_ppml/scripts_map.py. Every link opens the file or folder in the workspace. Rule of the workspace: whenever a script is added, retired, moved or changes purpose, the generator's categories and change log are updated and this page regenerated in the same step.

How the paper is produced. Nothing in the paper is typed from memory: every count comes from the evidence sheets through the data modules; every figure is drawn by a script as vector graphics from the same numbers; the build fills the text's placeholders, checks every number in every marked sentence against the cited record and refuses leftovers; independent scripts recount the tables and test the worded claims; the reference list comes from the database exports. Runbooks: scripts/README.md, search-ppml/README.md, notes-verifier/README.md, local-checker/README.md; the plan of each version: myliteraturereviewpaper/ppml2026/PLAN-V<n>.md.
